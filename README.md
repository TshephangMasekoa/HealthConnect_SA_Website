## Project Overview
BookWise SA is a fictional non-profit organisation that collects and distributes books to under-resourced schools in South Africa. They run reading programmes, book drives, and literacy workshops.

## Website Goals and Objectives
- Raise awareness about literacy challenges in South African schools
- Recruit volunteers for reading programmes
- Attract corporate sponsors and individual donors
- Provide schools with a way to request books

## Key Features and Functionality
- 5-page responsive website
- Homepage with impact stats and call-to-action
- About Us with team and mission/vision
- Programmes page detailing three initiatives
- Enquiry form for volunteers and school book requests
- Contact page with office address and contact form

## Timeline and Milestones
- Part 1 (Week 3): Complete HTML structure, 5 pages, navigation
- Part 2 (Week 6): CSS styling, responsive design
- Part 3 (Week 9): JavaScript validation, SEO, deployment

## Part 1 Details
- 5 HTML pages: index, about, programmes, enquiry, contact
- Semantic HTML5: header, nav, main, section, footer
- Functional navigation menu on all pages
- Image placeholders for all images
- Two forms: enquiry (volunteer/book request) and contact

## Design Process
The visual wireframes and mock-ups for this project were created using Figma, a collaborative design tool. Figma allowed for the rapid prototyping of page layouts and user interface elements.
